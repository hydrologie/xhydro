Welcome to xHydro's documentation!
==================================

**xHydro**: Hydrological analysis library built with xarray.

Need help?
^^^^^^^^^^

* If you encounter any errors or problems with `xHydro`, please let us know! Open an issue at the `GitHub main repository <https://github.com/hydrologie/xhydro>`_.
* To be aware of changes in `xHydro`, feel free to “watch” the GitHub repository. You can customize the watch function to notify you of new releases or more.
